    사용 매뉴얼

    시연 모드 (DEMO)

    1. 모드 개요

    시연 모드는 Project SOMA의 자세 및 시각적 활동 모니터링 기능을 짧은 시간 안에 확인하기 위한 모드입니다.

    일반 모드와 동일한 센서 수집 및 데이터 처리 구조를 사용하지만, 상태 변화와 피드백 동작을 빠르게 확인할 수 있도록 별도의 시연용 분석 정책과 시간 조건을 적용합니다.

    시연 모드는 실제 센서를 연결하여 사용할 수 있으며, Mock 센서를 이용한 가상 데이터 실행도 지원합니다. DEMO/NORMAL 모드 선택과 Mock 센서 사용 여부는 서로 독립적인 설정입니다.

    2. 측정 진행 과정

    1. 측정 시작: 실시간 측정 제어의 측정 시작 버튼을 누르면 시스템이 측정을 준비합니다.
    2. CALIBRATING(보정): 착석 압력과 사용자별 시각적 특성 등 초기 기준값을 수집합니다.
    3. READY(준비 완료): 보정이 완료되어 측정을 시작할 수 있는 상태입니다.
    4. MEASURING(실시간 측정): READY 상태에서 측정을 시작하면 센서 데이터를 바탕으로 분석을 수행합니다.
    5. 측정 종료: Frontend에서 측정 중지를 누르면 측정이 종료됩니다.

    3. 데이터 수집 및 분석

    SOMA는 다음 네 가지 항목을 기반으로 사용자 상태를 분석합니다.

    항목분석 내용
    Static(정적 자세)동일하거나 유사한 착석 자세가 지속되는 시간과 자세 변화
    Balance(압력 균형)FSR 4개 센서에서 측정한 착석 압력 분포
    Blink(눈 깜빡임)EAR(눈 종횡비) 기반 눈 깜빡임 횟수 및 빈도
    Distance(거리)보정된 기준과 비교한 사용자·화면 간 상대적인 거리 변화

    Chair의 압력·IR 센서 데이터는 약 1초 간격으로 전달되며, Vision은 Webcam에서 얻은 눈과 얼굴의 특징을 분석합니다.

    Blink Rate(눈 깜빡임 빈도)는 최근 60초 동안 검출된 눈 깜빡임을 기준으로 계산합니다.

    4. SOMA Score 계산

    SOMA Score는 100점에서 시작하며, 각 분석 항목에서 발생한 감점을 합산하여 산출합니다.

    SOMA Score = 100 − (Static + Balance + Blink + Distance 감점)

    최종 점수는 0~100 범위로 제한됩니다.

    시연 모드에서는 각 감점과 상태 판단에 시연용 정책을 적용하므로, 일반 모드보다 짧은 시간에 상태 변화와 피드백 동작을 확인할 수 있습니다.

    5. 상태 판정 및 피드백

    구분의미주요 피드백
    NORMAL정상적인 관측 상태녹색 LED
    CAUTION주의 조건 충족주황색 계열 알림
    DANGER경고 조건 충족적색 LED 및 경고
    ABSENT사용자 이석 감지측정 상태에 따른 표시 및 LED 제어
    BREAK휴식 권고 조건 충족파란색 LED 및 진동

    SOMA Score와 State(상태)는 별도의 정책으로 결정됩니다. 점수가 특정 수치에 도달했다는 이유만으로 반드시 CAUTION이나 DANGER가 발생하는 것은 아닙니다.

    또한 BREAK는 NORMAL·CAUTION·DANGER와 동일한 종류의 분석 상태가 아니라, 별도의 휴식 권고 피드백입니다.

    6. 시연 모드의 해석상 주의사항

    시연 모드의 시간 조건과 상태 변화는 기능 검증 및 발표를 위한 설정입니다.

    따라서 DEMO 모드에서 계산된 점수나 경고 발생 시간을 실제 사용 환경의 피로 누적 속도와 동일하게 해석해서는 안 됩니다.

    실제 모드 (NORMAL)

    1. 모드 개요

    실제 모드는 사용자의 착석 상태와 시각적 활동 관련 신호를 장시간 수집하고, 시간에 따른 부담 요소를 분석하는 모드입니다.

    Chair의 FSR 압력 센서 4개와 IR 거리 센서, Webcam 기반 Vision 데이터를 종합하여 SOMA Score 및 사용자 상태를 실시간으로 산출합니다.

    2. 측정 진행 과정

    측정 시작 → CALIBRATING → READY → MEASURING → 측정 종료

    측정 시작 후 초기 보정을 수행하며, READY 상태에서 측정을 시작하면 실시간 분석이 진행됩니다.

    측정 도중 사용자가 자리를 비우면 ABSENT 상태로 처리하며, 재착석 시에는 새로운 착석 구간에 맞는 기준으로 측정을 재개합니다.

    3. 데이터 수집 및 처리 주기

    데이터수집·분석 기준
    Chair 압력 센서FSR 4개, 약 1초 간격
    Chair IR거리값(mm) 측정
    VisionWebcam 기반 얼굴·눈 특징 추출
    Blink Rate최근 60초의 눈 깜빡임 횟수
    Sensor Fusion수신된 최신 유효 센서 데이터를 통합
    Score·State센서 데이터 및 정책의 시간 조건에 따라 갱신

    Vision 데이터의 신뢰도가 충분하지 않은 경우 해당 값을 무조건 감점에 사용하지 않고, 측정 유효성 조건에 따라 판단을 보류하거나 기존 분석 상태를 유지합니다.

    4. SOMA Score 계산 방식

    초기 SOMA Score는 100점이며, 다음 네 가지 분석 항목에서 발생한 감점을 합산합니다.

    SOMA Score = max(0, min(100, round(100 − Static − Balance − Blink − Distance)))

    ① Static — 정적 자세 누적 부담
    • 장시간 유사한 착석 자세를 유지할 때 누적 부담을 평가합니다.
    • 초기 유예시간은 300초(5분)입니다.
    • cumulative-v2 정책을 적용합니다.
    • 자세를 잠시 변경하더라도 누적된 정적 자세 부담이 즉시 전부 초기화되지는 않습니다.
    • 누적 감점 약 10점에서 Static 관련 CAUTION 조건, 약 20점에서 DANGER 조건에 도달할 수 있습니다.
    ② Balance — 착석 압력 불균형
    • 좌전·우전·좌후·우후의 FSR 센서값을 분석합니다.
    • 압력 분포의 불균형과 지속 여부를 평가합니다.
    • 유효한 착석 압력 데이터와 정책 조건을 만족할 때 감점에 반영합니다.
    ③ Blink — 눈 깜빡임 감소
    • Webcam으로 검출한 눈 특징점에서 EAR(Eye Aspect Ratio, 눈 종횡비)을 계산합니다.
    • 사용자별 EAR 기준을 보정하여 눈 감음과 뜸을 구분합니다.
    • 최근 60초의 Blink Rate를 계산합니다.
    • 분당 8회 미만의 낮은 눈 깜빡임 빈도가 지속되면 감점 조건을 평가합니다.
    • 저빈도 상태가 300초 지속되면 CAUTION, 900초 지속되면 DANGER 관련 조건을 평가합니다.
    • 분당 11회 이상으로 회복하면 Blink 감점 회복 조건을 적용합니다.
    ④ Distance — 거리 변화
    • Webcam 기반 얼굴 거리와 Chair IR 측정값을 활용합니다.
    • 초기 보정 기준에 대한 상대적인 거리 변화를 평가합니다.
    • 얼굴 방향이 크게 바뀌거나 거리 측정 신뢰도가 낮은 구간에서는 잘못된 감점을 방지하기 위해 판단을 보류할 수 있습니다.

    5. 상태 판정

    SOMA는 Score와 별도로 각 분석 항목의 조건 및 지속시간을 고려하여 상태를 판정합니다.

    상태의미
    NORMAL정상적인 분석 상태
    CAUTION주의가 필요한 분석 조건이 충족된 상태
    DANGER경고가 필요한 분석 조건이 충족된 상태
    ABSENT사용자의 이석이 감지된 상태

    상태는 Score의 단순한 구간 분류가 아닙니다.

    예를 들어 R25 실측에서 Static 감점이 약 10점에 도달했을 때 CAUTION, 약 20점에 도달했을 때 DANGER로 전환됐습니다. 이는 Static 정책 조건에 따른 결과이며, 모든 경우에 Score 90점과 80점이 상태 전환 기준이 되는 것은 아닙니다.

    6. 휴식 권고 및 하드웨어 피드백

    SOMA는 분석 상태에 따라 Frontend 표시와 Nano의 LED·진동 피드백을 제공합니다.

    상태·피드백동작
    NORMAL녹색 LED
    CAUTION주의 알림 및 NOTICE 피드백
    DANGER경고 알림 및 WARNING 피드백
    BREAK휴식 권고 및 별도의 LED·진동 패턴
    ABSENT이석 상태에 따른 LED 제어

    휴식 권고 정책은 다음과 같은 조건을 고려합니다.

    • DANGER 상태가 60초 이상 지속
    • SOMA Score 60점 이하가 120초 이상 지속
    • 연속 사용시간이 3,000초(50분)에 도달
    • 180초 이상의 유효 휴식 여부
    • 휴식 권고 후 900초의 재알림 제한시간

    각 조건은 측정 세션 상태와 우선순위에 따라 적용됩니다. 위 조건이 충족되더라도 다른 정책 조건에 따라 실제 알림 시점이 달라질 수 있습니다.

    7. 측정 결과 및 해석

    측정이 종료되면 저장된 기록을 Dashboard와 Session Report에서 확인할 수 있습니다.

    SOMA Score는 자세 및 시각적 활동과 관련된 센서 신호를 기반으로 계산한 시스템 내부 지표입니다.

    SOMA는 의학적 피로도 진단이나 질병 판정을 목적으로 하지 않으며, 측정된 상태는 사용자에게 휴식과 자세 변화를 안내하기 위한 참고 정보로 활용됩니다.
