    사용 매뉴얼

    시연 모드 (DEMO)

    1. 모드 개요

    시연 모드는 Project SOMA의 자세 및 시각 활동 모니터링 기능을 짧은 시간 안에 확인하기 위한 모드입니다.

    일반 모드와 같은 센서 수집 구조를 사용하지만, 상태 변화와 피드백을 빠르게 확인할 수 있도록 시연용 시간 조건과 분석 정책을 적용합니다.

    실제 센서와 Mock 센서를 모두 사용할 수 있으며, DEMO/NORMAL 선택과 Mock 사용 여부는 서로 독립적입니다.

    2. 측정 진행 과정

    로그인 → 측정 시작 → CALIBRATING → READY → MEASURING → 측정 종료

    1. 측정 시작: 측정 시작 버튼으로 인증된 세션을 시작합니다.
    2. CALIBRATING: 사용자 기준 자세와 유효 센서 표본을 수집합니다.
    3. READY: 보정이 완료됐음을 알리는 전환 단계입니다.
    4. MEASURING: Backend가 자동으로 실시간 측정 단계로 전환합니다.
    5. 측정 종료: 측정 중지 버튼으로 세션을 종료합니다.

    3. 데이터 수집 및 분석

    항목분석 내용
    Static유사한 착석 자세의 지속 시간과 자세 변화
    BalanceFSR 4개 센서의 착석 압력 분포
    BlinkEAR 기반 눈 깜빡임 횟수와 빈도
    Distance보정 기준 대비 얼굴 및 등받이 거리 변화

    Blink Rate는 최근 60초 동안 검출된 눈 깜빡임을 기준으로 계산합니다.

    4. Score와 상태

    SOMA Score = 100 − (Static + Balance + Blink + Distance 감점)

    최종 점수는 0~100 범위로 제한됩니다. State는 Score 구간만으로 정하지 않고 각 정책의 조건과 지속시간을 함께 반영합니다.

    구분의미주요 피드백
    NORMAL정상 관측 상태녹색 LED
    CAUTION주의 조건 충족NOTICE 피드백
    DANGER경고 조건 충족WARNING 피드백
    ABSENT사용자 이석 감지LED OFF
    BREAK별도 휴식 권고파란 LED 및 진동

    DEMO의 시간 조건은 기능 검증과 발표를 위한 설정이므로 실제 피로 누적 속도로 해석하지 않습니다.

    실제 모드 (NORMAL)

    1. 모드 개요

    실제 모드는 Chair의 FSR 압력 센서 4개와 IR 거리 센서, Webcam 기반 Vision 데이터를 종합하여 장시간 착석 부담을 분석합니다.

    측정 결과는 Backend가 계산한 Score·State·Reasons를 그대로 표시하며, Front가 별도의 판정을 만들지 않습니다.

    2. 측정 진행 과정

    로그인 → 측정 시작 → CALIBRATING → READY → MEASURING → 측정 종료

    측정 시작 후 Front는 Backend의 실제 유효 표본 진행률을 표시하며, READY 이후 MEASURING으로 자동 전환합니다. Stop은 보정 중에도 사용할 수 있습니다.

    3. 데이터 수집

    데이터수집·분석 기준
    Chair 압력FSR 4개 채널, 약 1초 간격
    Chair IR등받이 방향 거리값(mm)
    Vision얼굴·눈 특징, Blink Rate, 얼굴 거리
    Sensor Fusion최신 유효 센서 데이터 통합

    Vision 신뢰도가 충분하지 않은 구간은 무조건 감점하지 않고 정책에 따라 판단을 보류하거나 기존 값을 동결합니다.

    4. SOMA Score

    SOMA Score = max(0, min(100, round(100 − Static − Balance − Blink − Distance)))

    Static
    • Normal 기본 정책은 입니다.
    • 작은 순간 움직임만으로 누적 부담을 전부 초기화하지 않습니다.
    Balance
    • 유효한 착석 압력 분포와 지속 조건을 평가합니다.
    Blink
    • 사용자별 EAR 기준과 최근 60초 Blink Rate를 사용합니다.
    • Normal 기본 정책은 이며, 유효하지 않은 Vision 구간은 누적하지 않습니다.
    Distance
    • 보정 기준 대비 얼굴 거리와 Chair IR 변화의 유효한 증거를 함께 사용합니다.

    5. 상태와 피드백

    State는 Score의 단순 구간 분류가 아닙니다. 각 부담 요소의 조건과 지속시간에 따라 NORMAL, CAUTION, DANGER, ABSENT가 결정됩니다.

    BREAK는 Fusion State가 아니라 별도의 휴식 권고 피드백이며 Front 팝업과 Nano LED·진동으로 전달될 수 있습니다.

    6. 기록 확인

    Dashboard에서 현재 ACTIVE 기록과 저장된 종료 세션을 선택할 수 있습니다. 종료 세션의 History와 Session Report는 저장된 snapshot을 기반으로 표시됩니다.

    SOMA는 의학적 진단 도구가 아니며, 측정 결과는 휴식과 자세 변화를 안내하기 위한 참고 정보입니다.

    NORMAL 기술 용어

    장시간 같은 자세에서 생기는 Static 부담을, 짧은 움직임에 쉽게 지워지지 않도록 누적해서 평가하는 정책입니다.

    작동 방식

    • 확정된 각 자세 에피소드의 처음 300초(5분)는 신규 Static 감점 시간에 포함하지 않습니다.
    • 300초를 넘긴 유효 착석 시간만 전체 누적 시간에 한 번씩 더합니다.
    • 확정된 자세 변경은 새 자세 에피소드 시간을 0초부터 시작하지만, 이미 쌓인 Static 감점은 줄이거나 초기화하지 않습니다.
    • 센서가 무효이거나 5초를 넘는 데이터 공백에서는 누적 시간을 진행하지 않습니다.

    주요 기준

    • Static 감점 곡선의 상한은 25점입니다.
    • 누적 Static 감점이 10점 이상이면 Static 사유의 CAUTION, 20점 이상이면 DANGER 조건이 됩니다.
    • SOMA Score 자체는 모든 상태 전환에 공통으로 적용되는 단일 임계값이 아닙니다. State는 각 부담 요소의 조건과 지속시간을 함께 평가합니다.

    사용자별 EAR 보정이 유효할 때, 최근 Blink Rate가 낮은 상태의 지속시간을 Score 감점으로 반영하는 정책입니다.

    관측 신뢰성

    • 사용자별 OPEN EAR baseline과 개인화 threshold가 유효해야 합니다.
    • fallback threshold, 누락된 baseline, Blink Rate 누락 또는 최근 품질창의 얼굴 검출률 0에서는 타이머와 감점을 동결합니다.
    • Blink Rate는 최근 60초 동안 검출된 눈 깜빡임을 분당 횟수로 환산한 값입니다.

    시간·감점 기준

    • 분당 8회 미만이면 low-blink 시간을 누적합니다.
    • 300초까지는 Blink 감점 0점이며, 300초 초과부터 900초까지 0점에서 최대 10점으로 선형 증가합니다.
    • 분당 8회 이상 11회 미만에서는 low-blink 시간과 기존 감점을 유지합니다.
    • 분당 11회 이상이면 low-blink 시간은 초기화되고, 기존 Blink 감점은 최대 300초에 걸쳐 선형 회복합니다.
    • low-blink 시간이 300초 이상이면 CAUTION, 900초 이상이면 DANGER 조건이 될 수 있습니다. State와 Score는 독립 슬롯이므로 정확히 같은 순간에 변하지 않을 수 있습니다.
