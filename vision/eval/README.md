# 웹캠 정확도 분석

회의 항목 1 — *"눈깜박임 수 측정 및 **정확도 분석**"* 의 후반부입니다.

**측정하는 코드가 있다는 것과 그 값이 맞다는 것은 다릅니다.**
`vision/blink/ear.py` 의 임계값(`EAR_CLOSED=0.21`, `EAR_OPEN=0.25`)과
`vision/geometry.py` 의 `YAW_MAX` 는 지금 **문헌에서 흔히 쓰는 값일 뿐**,
이 카메라·이 피험자에 맞춘 값이 아닙니다. 여기 도구로 실측 기반으로 바꿉니다.

---

## 1. 깜빡임 정확도

### 녹화

```bash
python vision/eval/record.py --guided --subject S01 --glasses
```

화면이 초록으로 바뀌면 한 번 깜빡입니다. **신호 시각이 정답**이므로
혼자서도 정확한 ground truth 를 만들 수 있습니다.

EAR 시계열을 그대로 남기고 **검출은 하지 않습니다.**
임계를 바꿔가며 오프라인으로 재평가하려면 원본이 있어야 합니다.

관찰자가 옆에 있다면 `--guided` 없이 스페이스바 방식도 됩니다.
자연스러운 깜빡임을 잡지만 사람 반응 지연이 섞입니다.

### 스윕

```bash
python vision/eval/sweep.py vision/eval/data/S01.jsonl
python vision/eval/sweep.py "vision/eval/data/*.jsonl" --top 15
```

임계 조합별 **정밀도 / 재현율 / F1** 표가 나옵니다.
최적값을 `ear.py` 상수에 반영하세요.

```bash
python vision/eval/sweep.py --self-test    # 합성 신호로 스윕기 자체 검증
```

### 피험자별로도 돌리세요

전원을 합쳐 스윕하면 한 사람에게 과적합될 수 있습니다.
**한 명씩 따로 돌린 최적값이 서로 크게 다르면** 고정 임계로는 안 되고
개인 캘리브레이션이 필요하다는 뜻입니다.

### 안경

`--glasses` 로 기록해두고 착용/미착용을 나눠 비교하세요.
렌즈 반사와 프레임이 EAR 신뢰도를 떨어뜨리는데, 하필 표본 집단(대학생)의
착용률이 높습니다. **성능 차가 크면 발표에서 한계로 명시해야 합니다.**

## 2. 거리 정확도

```bash
python vision/eval/distance_check.py --calib-cm 60 --points 40 50 60 70 80
```

핀홀 근사(`얼굴폭 × 거리 = 상수`)가 실제로 얼마나 맞는지 잽니다.
캘리브레이션에 쓴 거리 하나로 **나머지 거리들이 얼마나 잘 나오는지**가 핵심입니다.

**자로 재세요.** 코 끝에서 카메라 렌즈까지입니다.
캘리브레이션 거리가 틀리면 상수가 통째로 틀립니다.

### 판정 기준

`fusion/state.py` 의 근접 임계는 **45cm** 입니다.
평균 오차가 5cm 를 넘으면 그 임계로 판정하기 어렵습니다 —
그때는 절대 거리 대신 **baseline 대비 변화량**으로 바꾸세요.
"평소보다 13cm 가까워짐" 이 "지금 47cm" 보다 방어하기 쉽습니다.

### 고개 돌림

고개를 옆으로 돌리면 얼굴 폭이 투영상 줄어 **"멀어졌다" 고 오판합니다.**
30도면 폭이 13% 줄어 60cm 가 69cm 로 보입니다.

보정 대신 **버립니다** — cos 로 되살리면 노이즈가 증폭되고, 큰 회전에서는
랜드마크 자체가 부정확해집니다. 거리는 초 단위로 변하는 값이라
프레임을 버려도 문제가 없습니다.

제외 프레임이 너무 많으면 `.env` 의 `VISION_YAW_MAX` 를 올리세요.
도구가 실행 중에 제외 프레임 수를 표시합니다.

## 실측 결과 — S01 (2026-09-06)

**표본 1명입니다.** 안경 미착용, 노트북 내장캠(1920x1080, 15fps), 실내 조명.
피험자가 신호 사이에 깜빡임을 참았으므로 90초 전체를 오검출 측정에 썼습니다.

### 프로토콜

```bash
python vision/eval/record.py --guided --subject S01          # 15초 버티기 + 75초 신호
python vision/eval/record.py --subject S01_natural --duration 60   # 자연 깜빡임
python vision/eval/sweep.py vision/eval/data/S01.jsonl \
       --natural vision/eval/data/S01_natural.jsonl
```

### 깜빡임 — 문헌값은 이 피험자에게 전혀 맞지 않았습니다

| 임계 | 신호 재현율 | 오검출/분 | 자연 깜빡임/분 (골 기준 21.0) |
|---|---|---|---|
| **0.21 / 0.25** (문헌, 이전 기본값) | **0.000** | 0.00 | 2.0 |
| 0.14 / 0.17 (절대값 실측) | 1.000 | 1.08 | 20.0 |
| **0.65 / 0.75 (평소 대비 비율) ← 채택** | **1.000** | **0.00** | **22.0** |

**이전 기본값으로는 깜빡임이 한 번도 검출되지 않습니다.** S01 의 평소 EAR 은
0.22 이고 회복 임계 0.25 는 그보다 높습니다. 상태기계가 "감김" 에서 빠져나오지
못해 분당 0회를 영원히 보고합니다. 값이 나오긴 하므로 실사용에서는 고장인 줄
모릅니다.

같은 사람인데도 두 녹화의 평소 EAR 이 **0.229 와 0.200** 으로 달랐습니다
(자세·조명·시간). 그래서 절대 임계가 아니라 최근 30초의 평소 EAR 대비
비율을 씁니다. `MAX_CLOSED_MS` 는 400 입니다 — 500 이면 자연 깜빡임이
26회/분으로 부풀었습니다.

### 채점 방법 — 신호 방식만으로는 오검출을 셀 수 없습니다

사람은 3~4초에 한 번 무의식적으로 깜빡이고 신호 간격도 4초입니다. 짝 없는
검출을 전부 오검출로 세면 검출기가 맞게 잡은 것을 틀렸다고 세게 됩니다.
그래서 녹화 앞에 **눈 뜨고 버티기 15초**를 두고 그 구간에서만 오검출을 셉니다.

검출은 신호보다 **중앙값 +0.67초** 늦습니다 (반응 시간 + 눈 감았다 뜨는 시간
+ 프레임 간격). 대칭 ±0.6초 창을 쓰면 맞게 잡은 것이 거의 전부 미검출로
기록됩니다 — 실제로 재현율 0.158 이 그렇게 나왔습니다. 창을 -0.3 ~ +1.5 로
둡니다.

자연 깜빡임에는 정답이 없으므로 **골(dip) 분석**을 기준으로 씁니다. 국소
baseline 대비 55% 아래로 내려간 구간을 셉니다. 신호 녹화에서 검증했습니다 —
정답 19개에 골 18개.

### 거리 — 정밀도는 좋고 정확도는 미검증

| | 얼굴 폭 | 환산 거리 | 세션 내 표준편차 |
|---|---|---|---|
| 캘리브레이션 | 449.1px | 60cm **(가정값)** | — |
| 신호 90초 | 382.5px | 70.4cm | 0.9cm |
| 자연 60초 | 351.9px | 76.6cm | 0.9cm |

핀홀 근사의 **반복성은 ±1cm** 로 좋습니다. 다만 캘리브레이션 거리가 자로 잰
값이 아니라 기본 가정값(60cm)이라 **절대 거리는 검증되지 않았습니다.**
실제가 55cm 였다면 모든 값이 0.92배입니다.

`fusion` 의 근접 임계는 45cm 인데 S01 은 70cm 대에 앉습니다. 절대 임계로는
이 사람에게 근접 경고가 영원히 뜨지 않습니다. `distance_check.py` 로 자로 재서
오차를 확인하고, 5cm 를 넘으면 baseline 대비 변화량으로 바꾸세요.

### 남은 것

- 피험자 1명입니다. 임계가 개인차를 감당하는지 확인하려면 2~3명이 더 필요합니다
- 안경 착용 녹화가 없습니다
- 거리 정확도 미측정 (`distance_check.py`)

### 거리 실측 — S01 카메라 (FaceTime HD 1920px, 2026-09-06)

자로 두 지점을 재서 이 **카메라의** 초점거리를 구했습니다. 사람이 바뀌어도
다시 잴 필요가 없습니다.

| 자로 잰 거리 | 홍채 | f_px | 홍채 추정 거리 | 오차 |
|---|---|---|---|---|
| 50cm | 33.2px | 1420 | 52.3cm | +4.5% |
| 70cm | 25.9px | 1549 | 67.1cm | -4.1% |

**채택: `VISION_FOCAL_PX=1484`** (화각 65.8°), 평균 절대오차 **2.6cm**.
판정 기준(5cm)을 통과하므로 `fusion` 의 45cm 절대 임계를 쓸 수 있습니다.

지점 간 f_px 편차가 8.7% 입니다. 홍채 px 는 프레임 간 표준편차가 1% 수준으로
안정적이므로 이 편차는 **자 쪽**입니다. 홍채 비율(33.2 / 25.9 = 1.282)이 가리키는
거리 비율은 1.282 인데, 50→70 이면 1.400 이어야 합니다. 두 측정 사이에 약 6cm
불일치가 있습니다. 자 기준점을 코끝에서 눈으로 옮겨도(2~5cm) 설명되지 않으므로
한 지점이 실제로 60cm 대였을 가능성이 큽니다.

**다음에 잴 때**: 지점을 3개 이상으로 늘리고 **눈에서 렌즈까지**를 재세요.
거리의 기준자가 홍채이므로 코끝이 아니라 눈이 있는 면이 기준입니다.

이 사람 얼굴 폭은 12.2cm 로 나왔습니다(지점 간 편차 0.41cm — 거리와 무관하게
일정하므로 측정 자체는 안정적입니다). 성인 평균(13~14.5cm)보다 작은데,
랜드마크 234/454 가 광대 최대폭이 아니거나 mediapipe 홍채가 10% 정도 크게
잡히는 것일 수 있습니다. **거리 정확도에는 영향이 없습니다** — 홍채만 쓰기 때문입니다.
