# UI 프로토타입 — 참고용

> **이 코드는 실행하지 마세요. 동작하지 않습니다.**
> 화면 디자인과 레이아웃만 참고하고, 배선은 새로 합니다.

`index.html` (479줄) 은 새 계약이 정해지기 전에 만들어진 대시보드 시안입니다.
UI 자산으로서의 가치는 있으나, 백엔드와 연결되지 않으며 폐기된 데이터 스키마를 씁니다.

---

## 가져다 쓸 것

| 자산 | 비고 |
|---|---|
| 전체 레이아웃 · 색 체계 | 그대로 재사용 가능 |
| 한/영 다국어 (`translations`) | 구조 그대로 |
| 4개 뷰 | `view-dashboard` / `view-monitoring` / `view-settings` / `view-info` |
| Chart.js 3종 | 실시간 라인 · 파이 · 타임라인 |
| 상태 카드 UI | 점수 링, 상단 상태 배너, 연결 표시등 |

## 버릴 것 — 왜 동작하지 않는가

**1. 연결 자체가 안 됩니다**

| | 이 시안 | 실제 백엔드 |
|---|---|---|
| 프로토콜 | raw WebSocket | **Socket.IO** |
| 주소 | `ws://127.0.0.1:8000/ws` | `0.0.0.0:5000` |

Socket.IO 는 별도 핸드셰이크를 쓰므로 raw WebSocket 클라이언트로 접속할 수 없습니다.
`socket.io-client` 로 교체해야 합니다.

**2. 데이터 필드가 존재하지 않습니다**

시안이 기대하는 값: `neck_angle`, `head_pitch`, `shoulder_tilt`, `posture_state`

- `neck_angle` 은 **코드에서 삭제된 함수**입니다 (거북목을 측정하지 못했음)
- 백엔드가 실제로 내는 값은 `balance_status`, `posture_status` — 이름도 값도 다릅니다

**3. 자세 교정 UI 는 범위 밖입니다**

`BAD_NECK` / `BAD_SHOULDER` / `BAD_COMPLEX` 상태와 "거북목", "척추 측만" 메시지는
**자세 판정을 삭제하기로 한 결정 이전**의 것입니다. 그대로 쓰면 안 됩니다.

**4. 정작 필요한 지표가 화면에 없습니다**

표시 중인 것은 자세 각도 3종뿐이고, 아래가 빠져 있습니다.

- 눈 깜빡임 수 (분당 / 저깜빡임 지속시간)
- 얼굴 ↔ 모니터 거리
- 압력 4채널, 적외선

**5. 팝업 알림이 없습니다**

`Notification` / `serviceWorker` 코드가 전혀 없습니다. 새로 구현해야 합니다.

**6. CDN 의존이 4개입니다**

Tailwind play CDN · Chart.js · Google Fonts · Pretendard.
**발표장 네트워크가 막히면 화면이 통째로 깨집니다.** 로컬 번들로 내려서 쓰세요.

## 새로 만들 때의 순서

1. `docs/contracts/state.json` 확정 — 어떤 필드가 오는지 먼저 정합니다
2. 위 "가져다 쓸 것" 을 `web/dashboard/` 로 옮깁니다
3. `socket.io-client` 로 배선, 표시 지표를 계약에 맞게 교체
4. Service Worker 팝업 추가 (브라우저 실행 중이어야 동작 — README 에 명시)
5. CDN 4종 로컬 번들화

> 이 시안이 남긴 교훈: **계약 없이 각자 만들면 포트조차 안 맞습니다.**
> 29KB 짜리 UI 가 존재하지 않는 필드를 기대하고 있었습니다. 계약을 먼저 고정하세요.
